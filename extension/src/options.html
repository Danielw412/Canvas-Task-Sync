Content acquisition defaults

Preferred modes automatically try the other method when the first method fails. “Both” requires both methods to succeed.

Automatic screenshot access

Chrome requires an optional all-sites capture grant for screenshots started by the website. The connector still opens only configured Google Docs URLs, never reads cookies, and does not need this grant for automatic text extraction.

Troubleshooting

  • Keep canvas-task-sync web running while sending a capture.
  • Open the file in Chrome and confirm the page is fully loaded before capturing.
  • If pairing fails after token rotation, paste the new token here.
  • For Sheets, select a bounded range when a workbook is very large.
  • The extension never reads Chrome cookies or exports login credentials.
